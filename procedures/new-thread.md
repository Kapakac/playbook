# Новый тред

## Когда предлагать

Предлагай Арсению перейти в новый тред, если выполнено хотя бы одно:

- задача сменилась;
- в треде больше 20 твоих сообщений;
- в тред вставлялись большие логи, вывод скриптов или файлы;
- было много шагов работы с репозиторием;
- ранняя часть треда больше не нужна для текущей работы.

Счётчика токенов у агента обычно нет, поэтому, если Арсений спрашивает о размере треда, оценивай по этим признакам и прямо говори, что это оценка.

## Как передать работу

Если Арсений согласился:

1. Запиши итог в ветку журнала (имя — в разделе проекта) в файл `journal/handoff/ГГГГ-ММ-ДД-<тема>.md`. Если ветки журнала у проекта нет, спроси Арсения, куда записать. Ветка журнала никуда не мёрджится.
2. Пиши коротко, не повторяй то, что уже есть в записи журнала за этот день. Разделы:

   ```
   # <тема>

   ## Задача
   ## Ветка, PR и CI
   ## Где остановились
   ## Проверено
   Что запускали и с каким результатом.
   ## Не проверено и предположения
   ## Открытые вопросы к Арсению
   ## Следующий шаг
   Одно конкретное действие.
   ## Ключевые файлы
   ```

3. Дай Арсению готовое первое сообщение для нового треда со ссылкой на этот файл.

## Как начать тред по файлу передачи

Если новый тред начинается со ссылки на файл передачи:

1. Прочитай этот файл и начни со «Следующего шага».
2. Состояние ветки, PR и CI сначала проверь на GitHub, а не бери из файла.
3. Актуальные `docs/` бери из `main`. Старые записи журнала и снимки docs не читай без необходимости.
