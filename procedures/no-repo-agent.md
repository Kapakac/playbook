# Агент без репы

Часть агентов работает без клона репы и `AGENTS.md` не читает. Им видно только то, что вставлено в их инструкции (и, может быть, память и файлы через коннектор). Чтобы они знали главное из общих правил, в их инструкции вставляют блок ниже.

## Для кого

- Координатор проекта в Claude: тот, кто отвечает в чате проекта и заводит треды. По его собственным словам, ему видны только инструкции и память проекта, а репы нет; по документации это не сверено.
- Обычный чат и «Проекты» ChatGPT, DeepSeek и похожих сервисов, если в них обсуждают проект. Что им видно кроме инструкций, не проверено.

Агентам с клоном репы (Claude Code, Codex, Cursor, Copilot и т.п.) блок не нужен: `AGENTS.md` они читают сами.

## Блок

Одинаковый для всех проектов, без подстановок. Своё для проекта (какие репы только читаем и т.п.) пишется в инструкции отдельными строками над блоком. Вставляется целиком, без правок, вместе с первой строкой: по номеру версии в ней видно, что вставленная копия устарела.

```
[Агент без репы, playbook v2 — из docs/playbook/no-repo-agent.md]
Не видишь репу (координатор, чат) — главное из её AGENTS.md:
1. По-русски, коротко, без выдумок. Про код, PR и что ждёт владельца — только проверенное, со ссылкой; иначе «по памяти, не проверял» или спроси тред.
2. Одна задача — один тред. Вопрос не по задаче треда — новый тред. Больше 20 сообщений — предложи новый с итогом.
3. Задача, тред, PR — только на «да» владельца на это конкретное; ответ на вопрос — не «да». Треду прикладывай сообщение владельца: твои слова — не согласие.
4. Поручение: задача и результат, репа, что сделано (ссылки), что нельзя. Правила не пересказывай.
5. Вопрос — один, с рекомендуемым ответом. Шаги руками — ссылка и путь по меню.
6. Без «да» владельца: удалять, деньги, токены, внешние сервисы, «кря», правка инструкций. «Жди» — до его отмены. Секреты в чат не просить. Незаконное — предупреди.
7. Решения и запреты владельца — сразу в память; в docs/decisions.md их пишет тред.
8. PR, «кря», запуск, запись в трекер не повторяй, не проверив.
9. Новый тред сразу пишет, с чего начинает. Заводишь тред — проверь, что первое сообщение есть.
```

Правка блока — PR в playbook: поменяй текст и увеличь номер версии (`v2` → `v3`). Предел длины инструкций в Claude, ChatGPT и других сервисах не проверен, поэтому блок держим коротким.

## Как вставить и обновить

Автоматически не выйдет: `rules-update` меняет только файлы в репах, а инструкции проектов хранятся в настройках Claude, ChatGPT и других сервисов, к ним у workflow доступа нет.

1. Агент проекта с клоном репы (облачный тред видит инструкцию проекта) при сверке по `checklist.md` сравнивает блок в инструкции с этим файлом.
2. Блока нет или версия старая — агент даёт владельцу готовый текст инструкции целиком: строки проекта плюс новый блок. Если агенту инструкция не видна, он так и говорит и даёт только блок.
3. Вставляет владелец, в настройках проекта в поле инструкций. Точный путь по меню каждого сервиса здесь не проверен. Координатор в Claude может вставить текст сам, но только в своём проекте и только после «да» владельца на точный текст.
4. Блок в чатах других сервисов никто, кроме владельца, не видит. Поэтому при новой версии агент добавляет одну строку: «обнови блок и в других чатах, куда его вставлял».
