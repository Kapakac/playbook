# Процедуры

Пошаговые порядки действий, общие для всех проектов. Источник — папка `procedures/` в репе Kapakac/playbook. В репе проекта это копия в `docs/playbook/`, её кладёт `make sync-rules`, а `make check-rules` в CI проверяет, что её не правили руками. Поправить процедуру — PR в playbook, потом `make sync-rules` в репе проекта.

Всё, что у проектов разное (команды, хелпер тестов, метка ящика, адресат «кря», журнал), процедуры берут из раздела «Проект» в `AGENTS.md` проекта.

- `prepare-pr.md` — открыть или обновить PR: проверки, ревью, описание, зелёный CI.
- `send-to-group.md` — отправить сообщение в Telegram («кря»).
- `quack-inbox.md` — проверить и разобрать ящик `/quack`.
- `new-thread.md` — когда предлагать новый тред и как передать в него работу.
- `journal.md` — журнал сессий. Необязательный: ведётся, только если это включено строкой в разделе проекта.
