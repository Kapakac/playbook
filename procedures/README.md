# Процедуры

Пошаговые порядки действий, общие для всех проектов. Источник — папка `procedures/` в репе playbook. В репе проекта это копия в `docs/playbook/`, её кладёт `make sync-rules`, а `make check-rules` в CI проверяет, что её не правили руками. Поправить процедуру — PR в playbook, потом `make sync-rules` в репе проекта.

Всё, что у проектов разное (ключ проекта, команды, автор коммитов, репа бота, хелпер тестов, метка ящика, адресат «кря», журнал), процедуры берут из раздела «Проект» в `AGENTS.md` проекта.

- `prepare-pr.md` — открыть или обновить PR: проверки, ревью, описание, зелёный CI.
- `spec.md` — спека в формате OpenSpec перед большой задачей: когда нужна, отдельный PR со спекой, сценарии в тесты, перенос в архив.
- `send-to-group.md` — отправить сообщение в Telegram («кря»).
- `quack-inbox.md` — проверить и разобрать ящик `/quack`.
- `shared.md` — разбор для других участников в ветке `shared`.
- `checklist.md` — сверить проект со списком «Что должно быть в проекте» из playbook, когда он поменялся.
- `new-thread.md` — когда предлагать новый тред и как передать в него работу.
- `no-repo-agent.md` — блок правил для инструкций агента, который не видит репу (координатор проекта, обычный чат), и как его обновлять.
- `tracker.md` — вести доску трекера задач. Только для проектов со строкой «Трекер: ведём» в разделе проекта.
- `journal.md` — журнал сессий. Необязательный: ведётся, только если это включено строкой в разделе проекта.
