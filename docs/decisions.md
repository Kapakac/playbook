# Принятые решения

Короткий список решений Арсения, которых нет в коде, `roadmap.md` и `stack.md`, или которые там легко пропустить. Новое решение дописывается сюда в том же PR, где оно появилось, новые сверху внутри раздела. Решение не удаляется, а помечается «отменено» с датой.

## Устройство

- 2026-10-30: общие правила для всех проектов, независимые от агента, лежат в репе `Kapakac/playbook`: `rules.md`, процедуры в `procedures/`, шаблоны и `init.sh`. В каждой репе проекта — `AGENTS.md` с общим блоком между метками, `CLAUDE.md` = `@AGENTS.md`, `make sync-rules` и проверка в CI. Это решение новее разбора «Общие правила для всех проектов» (там предлагалась репа `dev-rules` с общим `CLAUDE.md`, подключаемая к Claude-проектам) и заменяет его. Почему: одни и те же правила лежали копиями в инструкциях DS, МММ и бота и уже начали расходиться; `AGENTS.md` читают и другие агенты.
- 2026-10-30: блок в `AGENTS.md` — полная копия `rules.md`, а не ссылка: Codex не подключает файлы ссылкой. В метке записан коммит playbook. CI проекта падает, если блок или `docs/playbook/` поправили руками, и только предупреждает, если в playbook есть правила новее: иначе любое изменение правил ломало бы CI всех открытых PR во всех проектах.
- 2026-10-30: процедуры копируются в репу проекта (`docs/playbook/`), а не читаются из playbook: агент проекта может не иметь доступа к клону playbook.
- 2026-10-30: `sync-rules.sh` сам ничего не удаляет: файлы в `docs/playbook/`, которых больше нет в playbook, он только показывает.
- 2026-10-30: репа сейчас публичная, поэтому CI проектов клонирует её без токена. Следствие: никаких секретов, личных данных и данных Мосбиржи в ней. Если сделать её приватной, CI проектов понадобится токен с доступом к ней (решение Арсения).

## Общие правила

- 2026-10-30: расхождения между копиями правил сведены так. Ящик `/quack` — везде по строке «Просмотрено до №N» в `docs/duck-log.md`. Ветка: если среда агента назначила ветку сама (облачная сессия Claude), работаем в ней, иначе `<тема>-<суффикс>`. Имя ветки журнала — параметр проекта, существующие ветки не переименовываем. Значок — «⚠». Правило проекта важнее общего.
