# План

1. Playbook: общие правила, процедуры, шаблоны, `init.sh`, `make sync-rules` и проверка в CI.
2. Перевести на playbook существующие проекты: `AGENTS.md` с общим блоком, `CLAUDE.md` = `@AGENTS.md`, проверка в CI. Каждый — в своём проекте и своим PR.
3. Сократить инструкции Claude-проектов в claude.ai до своего (правит владелец).
4. Новые проекты стартуют сразу через `init.sh`.
5. Скиллы Claude (`prepare-pr`, `send-to-group`) в проектах свести к ссылке на `docs/playbook/`.
