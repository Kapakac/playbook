# Playbook

Общие правила для всех проектов владельца. Как устроена репа и как её править — `README.md`, прочитай его перед правкой.

Этот файл — для работы в самой репе playbook. Если она подключена к другому проекту только для чтения, правила и раздел «Проект» бери из `AGENTS.md` репы того проекта.

Общие правила — `rules.md` в корне этой репы: прочитай его и соблюдай.

Параметры вместо раздела «Проект»:

- Ключ проекта: `playbook`.
- Автор коммитов — аккаунт владельца репы на GitHub с его noreply-адресом GitHub.
- Меняем только эту репу. Репы проектов отсюда только читаем: на новые правила они переходят в своих проектах.
- Репа публичная: никаких секретов, имён, ников и других личных данных, названий и подробностей конкретных проектов.
- `rules.md` держим коротким, правило одного проекта сюда не кладём. Если после правки проектам нужно что-то сделать руками, это пишется в описании PR.
- Команды: `make lint` (shellcheck), `make test` (тесты скриптов).
- Ящика `/quack` нет, журнал не ведём, базы нет. «Кря» — только по прямой просьбе владельца, через репу общего бота.
- Внешние сервисы, которые в тестах не вызываем: GitHub.
