# История /quack

Разобранные заметки из ящика `/quack` (ветка `tg-inbox`, файл `duck.md`), новые сверху. Как проверять ящик — `docs/playbook/quack-inbox.md`. Номера общие для всех проектов, поэтому бывают пропуски.

Просмотрено до №0

Новое в ящике — номера больше, чем в строке выше. После разбора строка обновляется. Решения дополнительно пишутся в docs/decisions.md.

Формат записи:

```
## №N · ГГГГ-ММ-ДД · автор

Суть: что сказано, своими словами, 1–3 строки.
Итог: записали в decisions.md / заведена задача / только к сведению.
```
