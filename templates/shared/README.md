# Разборы для участников

Важные разборы, которые владелец хочет показать другим участникам проекта. Ссылки на них уходят в Telegram-группу вместе с короткой выжимкой.

Это не план проекта: план, стек и решения лежат в `docs/`.

Один разбор — один файл `ГГГГ-ММ-ДД-тема.md`, через отдельный PR. Как писать — `docs/playbook/shared.md`.
