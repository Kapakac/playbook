# Разборы для участников

Ветка `shared`: важные разборы, которыми владелец и участники проекта обмениваются друг с другом. Она отдельная от `main` и никуда не мёрджится: разбор попадает сюда коммитом, без PR. Раз в сутки общий бот сообщает в тему проекта в группе о новых коммитах в этой ветке.

Это не план проекта: план, стек и решения лежат в `docs/` в `main`.

Один разбор — один файл `ГГГГ-ММ-ДД-тема.md` в корне ветки. Как писать и что сюда класть нельзя — `docs/playbook/shared.md` в `main`. При каждом пуше workflow `secrets` ищет в новых коммитах ключи и токены.
